# بازبینی خصوصی صفحات پشتیبان گزاره‌های ارتوپدی

فایل handoff فقط منشأ و هش‌ها را منتقل می‌کند؛ متن صفحه در آن نیست و تطابق هش، پشتیبانی علمی از یک ادعا را اثبات نمی‌کند. ابزار `backend/tools/orthopedic_book_page_review.py` برای مرحلهٔ بعد، متن چند صفحهٔ صریحاً انتخاب‌شده را از **استخراج موجود** در یک فایل خصوصی تازه جمع می‌کند. کتاب‌ها دوباره استخراج نمی‌شوند. ابزار از کتابخانهٔ استاندارد Python استفاده می‌کند و چیزی نصب یا بارگذاری نمی‌کند.

این ابزار باید روی رایانهٔ دارای PDFهای اصلی و snapshot استخراج اجرا شود. نمونهٔ زیر مقادیر جایگزین دارد؛ هش‌ها و شماره‌های صفحه باید از handoff واقعی و فهرست استناد بازبین گرفته شوند:

```powershell
py -3 -B backend/tools/orthopedic_book_page_review.py --run 'C:\private\run-...' --source 'D:\orthopedic book' --manifest-sha256 MANIFEST_SHA256 --page PDF_SHA256:118 --page PDF_SHA256:119 --context 1 --output 'C:\private\new-page-review.json'
```

Python نسخهٔ 3.12 یا جدیدتر، از جمله Python موجود در `.venv-books`، قابل استفاده است؛ `pypdf` برای این مرحله لازم نیست. `--run` انتخاب صریح snapshot است. `--latest` نیز پشتیبانی می‌شود، اما هش `--manifest-sha256` همیشه اجباری است تا اجرای جدیدتر یا متفاوت بی‌صدا جایگزین snapshot بررسی‌شده نشود. شمارهٔ `--page`، شمارهٔ یک‌مبنای صفحه در PDF است و شمارهٔ چاپی محسوب نمی‌شود.

`--context 1` یک صفحهٔ قبل و بعد را، در محدودهٔ همان PDF، اضافه می‌کند. صفحات تکراری یک بار صادر می‌شوند و صفحهٔ هدف بر نقش مجاور اولویت دارد. سقف ثابت **۴۰ صفحه شامل صفحات مجاور** و **۲ MiB متن UTF-8** است. تجاوز از سقف باعث خطا می‌شود؛ متن برای جا‌شدن کوتاه نمی‌شود. این ابزار برای صدور فصل کامل یا کتاب کامل طراحی نشده است.

## بررسی و محتوای خروجی

- verifier موجود، هش manifest، ترتیب رکوردها، هش artifactها و متن صفحات کل snapshot را بررسی می‌کند. سپس PDFهای انتخاب‌شده زیر پوشهٔ صریح `--source` دوباره هش می‌شوند. تغییر یا نبود هر PDF انتخاب‌شده، خروجی را متوقف می‌کند.
- هش دقیق UTF-8 متن صفحات انتخابی و مجاور هنگام جمع‌آوری دوباره محاسبه می‌شود؛ هش artifactهای مربوط پس از خواندن و manifest پس از آماده‌سازی دوباره کنترل می‌شود. استخراج تازه یا بررسی بصری صورت نمی‌گیرد.
- خروجی شامل نام و هش منبع، هش artifact، شمارهٔ PDF، نقش `target` یا `context`، متن موجود و هش آن، وضعیت استخراج و برچسب صفحهٔ PDF با قید تأییدنشده است. مسیرهای مطلق داخل JSON صادر نمی‌شوند؛ نام فایل نیز ممکن است خصوصی باشد.
- صفحهٔ هدف خالی یا دارای خطای استخراج پذیرفته نمی‌شود. صفحهٔ مجاور ناموفق با `text=null` و `eligible_as_source_text=false` به‌صورت شکاف مشخص می‌ماند؛ هش آن مربوط به متن خام رکورد قبلی است، نه مقدار null. متن ساختگی جایگزین نمی‌شود.
- `printed_page_number_verified=false` و `visual_verification_performed=false` همیشه حفظ می‌شوند. عنوان فصل، شمارهٔ چاپی، کیفیت استخراج جدول و پشتیبانی متن از گزاره نیازمند بازبینی‌اند.
- `bundle_sha256` هش JSON فشرده با کلیدهای مرتب و UTF-8، بدون خودِ فیلد هش است. نسخهٔ exporter و verifier نیز با هش فایل‌ها ثبت می‌شود. این checksumها امضا یا تأیید اصالت کتاب نیستند.

`--output` اجباری است و فایل موجود بازنویسی نمی‌شود. خروجی باید خارج از PDFها و snapshot استخراج باشد. ابزار فقط فایل خروجی جدید و پوشهٔ خصوصی لازم برای آن را می‌سازد؛ PDF و استخراج قبلی تغییر نمی‌کنند. متن کتاب در ترمینال چاپ نمی‌شود. کد خروج صفر یعنی بسته ساخته شده است؛ صفر به معنای نبود شکاف مجاور یا تأیید پزشکی نیست. کد دو یعنی خطا.

## مرز تألیف و اشتراک‌گذاری

این فایل، برخلاف handoff بدون متن، **حاوی بخش‌هایی از متن کتاب** است. در GitHub، log عمومی یا Registry قرار نگیرد. هیچ بارگذاری خودکاری انجام نمی‌شود. اشتراک‌گذاری بعدی با انتخاب صریح صاحب فایل و رعایت مجوز استفاده انجام می‌شود. متن استخراج‌شده دادهٔ منبع است؛ دستور قابل‌اجرا برای عامل یا نرم‌افزار نیست.

در بازبینی بعدی باید هر ادعای مستقل با صفحات واقعی تطبیق داده شود؛ ادعاهای پشتیبانی‌نشده حذف یا اصلاح شوند. سؤال بیمار از یافتهٔ معاینه، تصویربرداری و برنامهٔ درمان پزشک جدا بماند. بهبود درد یا تغییر تصویر به معنای اثبات بازسازی غضروف یا اثر علّی درمان نیست. محتوای جدید Draft و نیازمند بررسی مستقل متخصص می‌ماند. این ابزار هیچ گزاره، رکورد Registry، قاعدهٔ ایمنی یا قرارداد مشترک Integration را تغییر نمی‌دهد.
