# مکمل تألیف Draft از منابع کتابی زانو

این مرحله ۹ پیشنهاد حاصل از مطالعهٔ هدفمند کتاب‌ها را با ۲۷ گزارهٔ بستهٔ پایهٔ زانو تطبیق می‌دهد. نتیجه **۸ پیشنهاد مستقل برای ایجاد Draft و ۱ پیشنهاد ارجاع پشتیبان برای مفهوم موجود** است. بستهٔ پایهٔ `knee_v1.json` و قراردادهای مشترک API تغییر نمی‌کنند.

در نمای تألیف، ۲۷ مفهوم پایه به‌علاوهٔ ۸ مفهوم پیشنهادی، ۳۵ مفهوم متمایز را پوشش می‌دهند. این عدد، شمار رکوردهای ایجادشده در Registry نیست. بارگذاری یا بررسی مکمل هیچ رکوردی ایجاد نمی‌کند و هیچ‌یک از گزاره‌های جدید Approved نیستند.

## فایل و مصرف‌کننده

- دادهٔ مکمل: [`backend/app/knowledge/knee_book_review_v1.json`](../backend/app/knowledge/knee_book_review_v1.json)
- Schema: [`backend/app/schemas/orthopedic_book_review.py`](../backend/app/schemas/orthopedic_book_review.py)
- بارگذاری و اعتبارسنجی: [`backend/app/services/orthopedic_book_review.py`](../backend/app/services/orthopedic_book_review.py)
- آزمون‌ها: [`backend/tests/test_orthopedic_book_review.py`](../backend/tests/test_orthopedic_book_review.py)

شناسهٔ Schema برابر `4b-mos.knee-book-review` و نسخهٔ آن `1.0.0` است. مکمل با `base_pack_manifest_sha256` به نسخهٔ مشخص بستهٔ پایه مقید می‌شود؛ ارجاع‌های مفهومی نیز نسخه و هش محتوای گزارهٔ پایه را نگه می‌دارند. تغییر بستهٔ پایه یا گزارهٔ مرتبط، نیازمند تطبیق و بررسی تازه است.

`load_knee_book_review_pack` مکمل را اعتبارسنجی می‌کند. `new_book_registry_proposals` فقط پیشنهادهای قابل‌بررسی از نوع `KnowledgeFactCreate` را برای ۸ مفهوم جدید برمی‌گرداند؛ این تابع واردسازی دیتابیس نیست. پیشنهادهای جدید از `BookDraftPreview` و منشأ صفحهٔ موجود استفاده می‌کنند. شرایط کاربرد، محدودیت‌ها، دامنهٔ شواهد و مشاهدهٔ بازبینی متنی، پیش از محاسبهٔ هش Registry در متن ساختاریافتهٔ گزاره مقید می‌شوند.

## تطبیق ۹ پیشنهاد

عبارت‌های این جدول بازنویسی کوتاه برای تألیف‌اند؛ هیچ متن کامل فصل یا جدول کتاب بازتولید نشده است. وضعیت تمام موارد **Draft، نیازمند بررسی مستقل متخصص** است.

پیشنهاد ۰۰۴ فقط از **مؤلفهٔ محل ضایعه** در مفهوم موجود پشتیبانی می‌کند. این ارجاع، تأیید تمام بندهای گزارهٔ گسترده‌تر مبتنی بر ICRS یا محتوای جایگزین آن نیست. برای این پیشنهاد payload ایجاد رکورد جدید تولید نمی‌شود.

همپوشانی سایر پیشنهادها ارتباط مفهومی است، نه تکرار همان ادعا: ۰۰۱ زمینهٔ تصمیم TKA را به بحث ساختار/علائم مرتبط می‌کند؛ ۰۰۳ محدودیت مشخص مک‌موری را بیان می‌کند؛ ۰۰۵ دربارهٔ متغیر ارزیابی است؛ ۰۰۷ دامنهٔ شواهد ترمیم منیسک را از راهنماهای PRP در OA جدا نگه می‌دارد؛ ۰۰۸ سازوکار پیشنهادی را از اثربخشی و توصیهٔ راهنما تفکیک می‌کند.

هش محتوای بستهٔ خصوصی، `page_review_bundle_sha256`، برابر است با:

```text

```

فایل عمومی مکمل فقط گزاره‌های بازنویسی‌شده، استناد و metadata منشأ را نگه می‌دارد. متن صفحات، تصاویر کتاب و مسیرهای مطلق خصوصی در آن قرار ندارند. هش PDFها و متن صفحات، یکپارچگی بایت‌ها را مشخص می‌کنند؛ امضا، تأیید اصالت کتاب یا اثبات پشتیبانی علمی از ادعا نیستند. متن دقیق صفحات در محیط بازبینی دوباره هش و با handoff تطبیق داده شد؛ تأیید بایت‌های PDF اصلی، گزارش اجرای ابزار محلی است.

## محدودیت‌های لازم برای تفسیر

- برای تمام موارد، سطح شواهد `ungraded` و بازبینی مستقل علمی و بالینی در انتظار است. مشاهدهٔ `ai_assisted_selected_text_checked` فقط بیان می‌کند متن منتخب با کمک هوش مصنوعی بررسی شده است؛ این مشاهده تأیید تخصصی مستقل نیست.
- تأیید بصری PDF انجام نشده است. شمارهٔ چاپی از سربرگ متن استخراج‌شده و مقایسه با مجاورها خوانده شد. در Campbell، اعداد 2336 و 2345 از سربرگ‌های شکستهٔ `233`+`6` و `234`+`5` بازسازی شده‌اند؛ برچسب PDF یا یک offset ثابت، تأیید شمارهٔ چاپی محسوب نمی‌شود.
- ۰۰۱ آستانهٔ جراحی یا صلاحیت بیمار تعیین نمی‌کند. ۰۰۲ امتیاز خطر یا فهرست آزمایش اجباری ایجاد نمی‌کند. ۰۰۳ حساسیت، ویژگی یا احتمال تشخیص ارائه نمی‌دهد.
- محل دردِ گزارش‌شده با محل ساختاری ضایعه یکسان نیست. وضعیت فیز نیز از سن یا گفتهٔ بیمار به‌تنهایی تأیید نمی‌شود.
- ۰۰۶ همهٔ پارگی‌های کم‌عروق را غیرقابل‌ترمیم نمی‌داند و روش جراحی انتخاب نمی‌کند.
- دربارهٔ ۰۰۷، همان صفحهٔ منبع متاآنالیزی با گزارش کاهش شکست ترمیم نیز نقل می‌کند؛ نتایج ناهمسو را نباید به «بی‌اثر بودن» تبدیل کرد. مطالعات اصلی و شواهد جدیدتر مستقیماً بازخوانی نشده‌اند. جدول کتاب یک مطالعهٔ trephination همراه PRP را زیر عنوان «PRP alone» قرار داده است؛ شرح مداخله برای طبقه‌بندی لازم است.
- ۰۰۸ فرضیهٔ سازوکار است. از بهبود درد، عملکرد یا تغییر تصویر، بازسازی غضروف یا اثر علّی درمان استنباط نمی‌شود. این سازوکار به HA، ACS، PL، اگزوزوم، SVF یا MSC تعمیم داده نمی‌شود.
- قید «معمولاً» و جمعیت محدود ۰۰۹ باید حفظ شود. این گزاره منع مطلق TKA یا توصیه و برتری resurfacing نیست.
- مطالب درمانی کتاب ۲۰۲۲ و راهنماهای تاریخی نقل‌شده در آن، جمع‌بندی شواهد روز محسوب نمی‌شوند. کیفیت استخراج جدول‌ها، اصالت و شناسنامهٔ نسخه، مقابلهٔ بصری صفحات و به‌روزترین منابع همچنان نیازمند بررسی‌اند.

## مرز این مرحله و مرحلهٔ بعد

این مکمل از Registry موجود استفاده می‌کند و پایگاه دانش موازی ایجاد نمی‌کند. بارگذاری، اعتبارسنجی و استخراج payloadهای پیشنهادی هیچ واردسازی، تأیید پزشکی، migration، دسترسی به بیمار یا فعال‌سازی قاعدهٔ ایمنی انجام نمی‌دهند. Clinical Safety Rule Engine موجود مرجع قواعد ایمنی باقی می‌ماند.

سؤال بیمار، نتیجهٔ معاینه، یافتهٔ تصویربرداری و برنامهٔ پزشک در این مرحله به هم تبدیل نمی‌شوند. پرسشگر، رتبه‌بندی افتراق‌ها، احتمال تشخیص و برنامهٔ درمان تغییر نکرده‌اند. اتصال این مکمل به مسیر پرسشگری و خروجی Clinical Integration مرحلهٔ جداگانه‌ای است و باید با قراردادهای همان مسیر هماهنگ شود.

برای بازبینی فنی محلی می‌توان مکمل را بارگذاری کرد:

```bash
python -B -c "from backend.app.services.orthopedic_book_review import load_knee_book_review_pack; p = load_knee_book_review_pack(); print(p.pack_key, len(p.entries), p.status)"
python -B -m pytest backend/tests/test_orthopedic_book_review.py -q
```

موفقیت این فرمان‌ها، تأیید پزشکی یا مجوز استفادهٔ عملیاتی از محتوای Draft ایجاد نمی‌کند.
