# دریافت منابع علمی تازه، پیش از بررسی تخصصی

یک مسیر اختیاری، رایگان و قابل اجرای محلی برای کشف **اطلاعات کتاب‌شناختی** مقالات PubMed از API رسمی Europe PMC اضافه شد. این مسیر جای Medical Knowledge Registry یا Clinical Evidence Briefs موجود را نمی‌گیرد. مقالهٔ پیدا‌شده، شواهد ارزیابی‌شده یا دانش Approved نیست.

## اجرای واقعی این مرحله

در ۲۶ اکتبر ۲۰۲۶، دریافت زندهٔ سه رکورد برای موضوع `knee_oa` با بازهٔ آغاز ۲۰۲۵/۰۱/۰۱ موفق شد؛ پاسخ سرویس ۶۷۱ نتیجهٔ کلی گزارش کرد و فقط صفحهٔ محدود سه‌تایی درخواست شد. [خروجی واقعی](examples/orthopedic-evidence-watch-live-2026-10-26.json) زمان UTC، پرس‌وجوی دقیق، PMID/DOI، نوع انتشار گزارش‌شده و هش پاسخ را نگه می‌دارد. این فایل دادهٔ تست ساختگی نیست؛ snapshot اطلاعات عمومی ارائه‌دهنده است. متن مقاله یا abstract ذخیره نشده است.

رکوردها، طبق دادهٔ ارائه‌دهنده:

- PMID [42918921](https://pubmed.ncbi.nlm.nih.gov/42918921/)، DOI `10.1007/s00402-026-06543-6`، تاریخ گزارش‌شده ۲۰۲۶/۱۰/۲۲؛ نامزد مرور ساختاری PRP. **از عنوان یا نوع انتشار هیچ نتیجه‌ای دربارهٔ بازسازی غضروف یا اثربخشی گرفته نشده است.**
- PMID [42927343](https://pubmed.ncbi.nlm.nih.gov/42927343/)، DOI `10.2147/cia.s638393`، تاریخ گزارش‌شده ۲۰۲۶/۱۰/۲۰؛ نامزد مطالعهٔ گزارش‌شده به‌عنوان RCT.
- PMID [42920564](https://pubmed.ncbi.nlm.nih.gov/42920564/)، DOI `10.3389/fmed.2026.1903675`، تاریخ گزارش‌شده ۲۰۲۶/۱۰/۰۹؛ عنوان آن تحلیل کتاب‌سنجی است، هرچند metadata برچسب systematic review برگرداند. این نمونه نشان می‌دهد فیلتر پایگاه به‌تنهایی کیفیت یا نوع واقعی مطالعه را تأیید نمی‌کند.

روش، جمعیت، نتایج، دسترسی متن کامل، وضعیت مستقل اصلاح/پس‌گرفتن و تاریخ دقیق انتشار این سه مقاله بررسی نشده‌اند. نبود پرچم retraction در metadata به معنی بررسی و رد پس‌گرفتن نیست. هیچ‌کدام به گزاره یا توصیهٔ بالینی تبدیل نشده‌اند.

## استفاده

```bash
# بدون شبکه: فقط طرح درخواست و وضعیت online_not_requested
.venv/bin/python -B -m backend.tools.orthopedic_evidence_watch --topic knee_oa

# دریافت صریح یک صفحهٔ محدود از metadata؛ خروجی JSON فقط روی stdout
.venv/bin/python -B -m backend.tools.orthopedic_evidence_watch --topic knee_oa --since 2025-01-01 --max-records 3 --online
```

موضوع‌ها بسته‌اند: `knee_oa`، `meniscus`، `cartilage` و `orthobiologics`. ورودی متن بیمار، سؤال آزاد، شناسهٔ بیمار، URL دلخواه یا کلید اشتراک وجود ندارد. حداکثر ۲۰ رکورد، پاسخ ۵۱۲KB و timeout پانزده‌ثانیه‌ای اعمال می‌شود. HTTPS با تأیید TLS و proxy محیط حفظ می‌شود و redirect دنبال نمی‌شود. خطای دسترسی/timeout/قالب/حجم با وضعیت شکست برمی‌گردد؛ نتیجهٔ ذخیره‌شده به‌جای دریافت ناموفق جا زده نمی‌شود.

خروجی همهٔ رکوردها Draft، نیازمند بررسی مستقل، کیفیت `unassessed` و دسترسی `bibliographic_metadata_only` است. تاریخ و نسخهٔ منبع که تأیید نشده‌اند صریح می‌مانند. `record_payload_sha256` هش رکورد دریافتی است، `source_payload_sha256` هش بایت پاسخ API؛ هیچ‌کدام هش متن مقاله یا تأیید صحت علمی نیستند.

منابع فنی: [مستندات رسمی REST](https://europepmc.org/RestfulWebService) و [راهنمای رسمی API](https://europepmc.org/docs/EBI_Europe_PMC_Web_Service_Reference.pdf). نمایهٔ رسمی پارامترهای JSON/lite، pageSize و FIRST_PDATE بررسی شد؛ دسترسی مستقیم مستندات 403 بود. خود endpoint در اجرای واقعی پاسخ موفق داد.

## ارتباط با پزشکیار

ترتیب لازم: کشف منبع → بررسی متن و روش → بررسی جمعیت و اختلاف راهنماها → تألیف گزارهٔ Draft با منشأ → بازبینی مستقل در Registry موجود → استفادهٔ نسخه‌بندی‌شده پس از تأیید. کشف آنلاین در مسیر پاسخ بیمار یا موتور ایمنی فعال نشده و خودکار قواعد یا طرح درمان را عوض نمی‌کند.

این جستجو مرور نظام‌مند، تضمین پوشش آخرین اطلاعات دنیا یا پایش کامل تغییر راهنماها نیست. ترتیب تاریخ انتشار، رتبهٔ درمان نیست. scheduler یا اشتراک خارجی نصب نشده؛ فعلاً اجرای صریح توسعه‌دهنده است. برنامه‌ریزی پایش دوره‌ای و اتصال صف بازبینی به Registry به هماهنگی Integration نیاز دارد.
