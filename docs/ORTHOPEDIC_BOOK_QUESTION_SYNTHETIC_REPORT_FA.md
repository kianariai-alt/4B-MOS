## محدودیت تفسیر

- دامنهٔ بازبینی، انتخاب صریح پزشک در محیط تألیف است؛ تشخیص یا تأیید تناسب منبع با بیمار نیست.
- موضوعات مک‌موری، محل ضایعه، بلوغ اسکلتی، خون‌رسانی، جزئیات مداخله و پیامدهای تفکیکی در ورودی مشترک فعلی فیلد ندارند؛ وضعیت آن‌ها `not_represented_in_context_v1` است و نبودشان دستور معاینه یا تصویربرداری ایجاد نمی‌کند.
- کارت پیامدهای PRP فقط با سابقهٔ درمان کامل و سازگار ظاهر می‌شود؛ سابقهٔ درمان به‌تنهایی نوع درمان یا دریافت PRP را تأیید نمی‌کند.
- مورد ۰۰۴ تنها ارجاع پشتیبانِ مؤلفهٔ محل ضایعه است؛ هش مدخل کتابی از هش گزارهٔ پایه جدا نگه داشته می‌شود.
- فرضیهٔ سازوکار PRP، کاهش درد یا تغییر تصویر به اثبات بازسازی غضروف، برتری یا اثر علّی درمان تبدیل نمی‌شوند.
- API قبلی، بانک سؤال موجود و بستهٔ پایه تغییر محتوایی نکرده‌اند. این خروجی، اعتبارسنجی مستقل پزشکی نیست.
